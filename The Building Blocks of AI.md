# Class — Introduction to AI & AI Security

- AI is changing many industries, including **cybersecurity**.
- **AI (Artificial Intelligence)** is the broad concept of machines performing tasks that normally require human intelligence.
- **ML (Machine Learning)** is a subset of AI where systems learn patterns from data.
- ML mainly includes:
  - **Supervised Learning** – learns from labelled data.
  - **Unsupervised Learning** – finds patterns in unlabelled data.
  - **Reinforcement Learning** – learns through rewards and penalties.
- **Deep Learning** is a subset of ML that uses neural networks with multiple layers.
- **Neural Networks** are models made of connected layers that learn patterns using weights.
- **LLM (Large Language Model)** is a type of AI model designed to understand and generate human language.
- LLMs learn from large amounts of data and generate responses by predicting the next token.
- AI/ML can be used in cybersecurity for **threat detection, malware analysis, fraud detection, automation, and vulnerability discovery**.
- Attackers can also use AI for **phishing, social engineering, reconnaissance, malware, and automating attacks**.
- AI systems themselves introduce **new security risks and attack surfaces**.
- The main goal of this class is to understand **AI, ML, Deep Learning, Neural Networks, and LLMs** before learning AI/LLM security.

# Class — Machine Learning Algorithms

- ML algorithms are mathematical methods used to **learn patterns from data**.
- The trained output of an ML algorithm is called an **ML model**.
- ML algorithms follow a basic loop:
  - Decision process → makes predictions
  - Error function → measures prediction errors
  - Model optimisation → adjusts the model to improve performance
- This process repeats until the model reaches a satisfactory performance level.
- ML algorithms have **four main categories**:
  - **Supervised Learning** – learns from labelled data.
  - **Unsupervised Learning** – finds patterns and structure in unlabelled data.
  - **Semi-supervised Learning** – uses a small amount of labelled data with a larger amount of unlabelled data.
  - **Reinforcement Learning** – learns by taking actions and receiving rewards or penalties.
- Supervised learning examples: **house price prediction, spam classification**.
- Unsupervised learning examples: **customer grouping, network anomaly detection**.
- Reinforcement learning is used in **game-playing AI and autonomous systems**.

# Class — Neural Networks & Deep Learning

- Neural networks are used to enable computers to behave more like humans.
- Neural networks are inspired by how **neurons and synapses** work in the human brain.
- A neural network consists of:
  - **Input layer** – receives raw data.
  - **Hidden layers** – process data and extract patterns/features.
  - **Output layer** – produces the final prediction.
- Each connection between nodes has a **weight** that determines its influence.
- In image recognition, early layers detect simple features, while deeper layers detect more complex patterns.
- **Deep Learning (DL)** refers to neural networks with more than three layers.
- Deep Learning can work with **raw, unstructured data** and learn features automatically.
- Deep Learning can process very large datasets, making it a **scalable form of ML**.
- The growth of Deep Learning was driven largely by the availability of **large amounts of digital data**.

# Class — Large Language Models (LLMs)

- **LLMs are deep learning-based AI models** that process and generate text by predicting the next word/token.
- LLMs are first trained through a **pre-training** phase using huge amounts of text data.
- LLMs use **billions of parameters** to encode what the model learns about language.
- During training, the model predicts the missing/next word and adjusts its parameters using **backpropagation**.
- **GPUs** make large-scale LLM training possible through parallel processing.
- LLMs are built using **Transformer neural networks**.
- Transformers use **attention** to determine which words are important based on context.
- **RLHF (Reinforcement Learning from Human Feedback)** uses human feedback to improve model outputs after pre-training.
- LLMs power **Generative AI** products that can generate text and other content.
- **AI → ML → Deep Learning → LLM**
- AI is the broad field.
- ML is a subfield of AI that learns from data.
- Deep Learning is a subfield of ML using neural networks.
- LLMs are advanced Deep Learning models based on **Transformers**, designed to understand and generate human-like text.
